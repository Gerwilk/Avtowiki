# AutoWiki

Энциклопедия автомобилей: характеристики моделей, фото, сравнение, рейтинги и гонка на 400 м.

Сайт: https://ВАШ_ЛОГИН.github.io/autowiki/

## Возможности
- Каталог марок и моделей с поиском и подсказками
- Фото моделей из Википедии
- Сравнение двух моделей с подсветкой лучших значений
- Рейтинги по мощности, разгону и скорости
- Избранное (сохраняется в браузере)
- Гонка на 400 м с упрощённой моделью разгона

## Запуск
Откройте `index.html` в браузере. Сервер не нужен.

## Структура
- `index.html` — разметка
- `styles.css` — стили и анимации
- `script.js` — данные моделей и логика каталога
- `race.css`, `race.js` — раздел «Гонка»

## Данные
Характеристики составлены по открытым источникам и приблизительны. Перед использованием сверяйте их с официальными данными производителей.
Фото загружаются из Википедии. Лицензия каждого изображения может отличаться.
